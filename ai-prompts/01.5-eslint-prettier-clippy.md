# Batch 01.5：配置自动化代码质量检查

> 此批次在 Batch 01（Rust 基础设施）完成后、Batch 02（类型定义）之前执行。
> 目的：配置自动检查工具，后续每批次代码生成后自动拦截低级错误。

---

你是一个 TypeScript / Vue 3 / Rust 代码生成专家，为 invest-record-pro 项目提供高质量代码。

## 任务

在已有 Tauri + Vue 项目中配置以下自动化检查工具。

## 1. ESLint（TypeScript/Vue 代码规范检查）

### 安装

```bash
npm install -D eslint @eslint/js typescript-eslint eslint-plugin-vue
```

### 创建 `eslint.config.js`

```js
import js from '@eslint/js'
import tseslint from 'typescript-eslint'
import pluginVue from 'eslint-plugin-vue'
import vueParser from 'vue-eslint-parser'

export default [
  js.configs.recommended,
  ...tseslint.configs.recommended,
  ...pluginVue.configs['flat/essential'],
  {
    files: ['**/*.vue'],
    languageOptions: {
      parser: vueParser,
      parserOptions: {
        parser: tseslint.parser,
        ecmaVersion: 'latest',
        sourceType: 'module'
      }
    }
  },
  {
    files: ['src/**/*.{ts,vue}'],
    rules: {
      // 禁止 any 类型（核心规则）
      '@typescript-eslint/no-explicit-any': 'error',
      // 禁止未使用的变量
      '@typescript-eslint/no-unused-vars': ['error', { argsIgnorePattern: '^_' }],
      // 禁止 console.log（改为 console.error 允许）
      'no-console': ['error', { allow: ['warn', 'error'] }],
      // Vue 规则
      'vue/multi-word-component-names': 'off',
      'vue/no-unused-vars': 'error',
    }
  },
  {
    ignores: ['dist/', 'src-tauri/', 'node_modules/', '*.d.ts']
  }
]
```

### 在 `package.json` 中添加 scripts

```json
{
  "scripts": {
    "lint": "eslint src/",
    "lint:fix": "eslint src/ --fix",
    "type-check": "vue-tsc --noEmit"
  }
}
```

### 安装 vue-tsc

```bash
npm install -D vue-tsc
```

## 2. Prettier（代码格式统一）

### 安装

```bash
npm install -D prettier eslint-config-prettier
```

### 创建 `.prettierrc`

```json
{
  "semi": false,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "all",
  "printWidth": 100,
  "vueIndentScriptAndStyle": false
}
```

### 更新 `package.json` scripts

```json
{
  "scripts": {
    "format": "prettier --write \"src/**/*.{ts,vue,css}\"",
    "format:check": "prettier --check \"src/**/*.{ts,vue,css}\""
  }
}
```

## 3. Clippy（Rust 代码规范检查）

Rust 自带 Clippy，无需安装。确保 `Cargo.toml` 中有：

```toml
[lints.clippy]
unwrap_used = "deny"
expect_used = "deny"
panic = "deny"
```

在 `src-tauri/src/main.rs` 顶部添加：

```rust
#![deny(clippy::unwrap_used)]
#![deny(clippy::expect_used)]
```

## 4. 模块依赖检查脚本

创建 `scripts/check-cross-deps.sh`，检查 features 模块之间是否违规互相导入：

```bash
#!/bin/bash
# 检查 features 模块之间是否违规互相导入
# 规则：features/xxx 不得 import features/yyy
# 只允许导入 shared/*, services/*, domain/types/*

echo "=== 检查跨模块依赖 ==="

VIOLATIONS=$(grep -rn "from ['\"]@/features/" src/features/ --include="*.ts" --include="*.vue" 2>/dev/null || true)

if [ -z "$VIOLATIONS" ]; then
  echo "✅ 无违规跨模块依赖"
else
  echo "❌ 发现违规跨模块依赖："
  echo "$VIOLATIONS"
  exit 1
fi
```

给脚本执行权限：`chmod +x scripts/check-cross-deps.sh`

## 5. 统一验证命令

在 `package.json` 中添加一个 `check` 命令，一键执行所有检查：

```json
{
  "scripts": {
    "check": "npm run lint && npm run type-check && npm run format:check && bash scripts/check-cross-deps.sh",
    "check:fix": "npm run lint:fix && npm run format"
  }
}
```

Rust 侧检查命令：`cargo clippy -- -D warnings`

## 验证

配置完成后运行：

```bash
npm run check
```

- ESLint、vue-tsc、Prettier、跨模块检查全部通过
- 注意：当前项目还没有业务代码，`npm run check` 应该无报错即可
