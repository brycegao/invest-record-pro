# Invest Record Pro

本地隐私优先的个人投资决策记录系统 | 纯端侧桌面应用 | 本地AI复盘

## ✨ 核心特性

- ✅ **100% 本地运行**：数据不上云、不联网、不依赖服务器
- ✅ **隐私安全**：所有交易记录、计划、复盘存在本地 SQLite
- ✅ **本地 AI 复盘**：接入 Ollama 本地大模型，离线生成投资总结
- ✅ **完整投资闭环**：标的管理 → 交易计划 → 交易记录 → 仓位统计 → 深度复盘
- ✅ **纪律量化**：自动统计「计划执行率」，改善投资行为
- ✅ **Windows / macOS 双端支持**
- ✅ **轻量高性能**：安装包 < 10MB，启动秒开

## 🎯 适用人群

- 重视数据隐私的个人投资者
- 坚持交易纪律、需要系统化复盘的人
- 喜欢本地 AI、纯端侧工具的用户
- 股票 / ETF / 基金 交易者

## 🛠️ 技术栈

- **前端**：Vue3 + TypeScript + Element Plus
- **客户端**：Tauri + Rust
- **数据库**：SQLite（本地文件）
- **本地 AI**：Ollama
- **图表**：ECharts

## 🚀 核心功能

1. **投资标的管理**：记录代码、类型、风险、投资逻辑
2. **交易计划制定**：提前写好买入/卖出纪律，不临盘决策
3. **交易记录录入**：记录价格、仓位、情绪、是否遵守计划
4. **仓位分析**：资产分布、仓位占比、风险监控
5. **深度复盘系统**：单笔复盘 + 月度复盘
6. **本地 AI 助手**：AI 生成复盘、优化建议、行为分析
7. **数据备份导出**：Excel / PDF 导出，本地备份
