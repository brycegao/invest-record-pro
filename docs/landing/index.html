常见问题 / FAQ

我的数据会上传到云端吗？ / Will my data be uploaded to the cloud?

不会。所有数据存储在本地 SQLite 数据库中，没有任何网络传输。
No. All data is stored in a local SQLite database. There is zero network transmission.

AI 复盘需要联网吗？ / Does AI review require internet?

不需要。AI 功能基于 Ollama 本地大模型运行，完全离线可用。
No. AI features run on local LLMs via Ollama and work fully offline.

支持哪些平台？ / Which platforms are supported?

Windows 10/11 和 macOS。Linux 支持计划中。
Windows 10/11 and macOS. Linux support is planned.

开源版本是否永久免费？ / Is the open-source version permanently free?

是的。基础功能永久免费，MIT 协议开源。高级功能以可选付费插件形式提供。
Yes. Core features are permanently free under the MIT license. Advanced features are offered as optional paid plugins.

如何使用 AI 功能？ / How to use AI features?

需要在本机安装 Ollama 并下载一个推荐模型（如 qwen2.5），然后在本工具设置中配置 Ollama 地址即可。
Install Ollama locally, download a recommended model (e.g. qwen2.5), and configure the Ollama endpoint in the app's settings.
